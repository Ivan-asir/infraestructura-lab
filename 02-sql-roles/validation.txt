VALIDACIÓN | 02 - SQL, ROLES Y PERMISOS
=======================================

1) CONTEXTO
- Entorno: base tienda en pg-primary; esquema public.
- Alcance: datos de prueba, roles NOLOGIN, permisos y transacciones.
- Estado: VALIDADO.

2) COMPROBACIONES Y RESULTADOS
- Recuentos: clientes=24; productos=100; pedidos=200; pedido_items=200.
- Clientes sin pedidos: 4 (IDs 21, 22, 23 y 24).
- Roles: tienda_readonly y tienda_readwrite; rolcanlogin=f en ambos.
- Permisos: tienda_readonly tiene SELECT (r) en las cuatro tablas.
- Permisos: tienda_readwrite tiene INSERT, SELECT, UPDATE y DELETE
  (arwd) en las cuatro tablas; acceso rU a las secuencias listadas.
- Lectura con SET ROLE tienda_readonly: COUNT(clientes)=24.
- Escritura como tienda_readonly: ERROR "permiso denegado a la tabla productos"
  (resultado esperado, control de permisos correcto).
- INSERT con tienda_readwrite: INSERT 0 1; se ejecutó ROLLBACK.
- Validación final: productos=100; productos_de_prueba=0.

3) INCIDENCIAS Y LIMITACIONES
- El error de permiso es una prueba negativa deliberada, no una incidencia.
- Se resumen las concesiones observadas; consultar roles.sql para la definición.

4) ESTADO FINAL Y REVERSIÓN
- ROLLBACK probado: la inserción de prueba no persistió.
- La carga inicial permaneció con 100 productos.

5) CONCLUSIÓN
- Datos, lectura/escritura segregadas y reversión transaccional validados.
