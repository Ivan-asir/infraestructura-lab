# Plantilla para documentar incidencias

Si una práctica tiene incidentes relevantes, su archivo `troubleshooting.md` utiliza estos títulos, en orden:

```markdown
# Práctica — incidencia

## 1. Síntoma y alcance
## 2. Entorno y evidencias previas
## 3. Diagnóstico
## 4. Corrección aplicada
## 5. Validación posterior
## 6. Reversión y recuperación
## 7. Estado y pendientes
```

No crear un archivo vacío si no hubo incidencias. No atribuir causa confirmada cuando solo exista correlación. Indicar comandos reales y evidencias protegidas; no publicar tokens, claves ni contraseñas.
